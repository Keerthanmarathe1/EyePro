# 👁️ EyePro

### Control your computer using your eyes.

EyePro is a computer-vision based application that allows users to interact with their computer using **eye movements and blinks**.

Built with Python, OpenCV, MediaPipe and PyAutoGUI.

---

## ✨ Features

- 👀 Real-time eye tracking
- 🖱️ Eye-controlled cursor movement
- 😉 Blink detection
- 🖱️ Blink-to-click interaction
- 🎥 Real-time webcam processing
- ⚡ Lightweight and responsive

---

## 🧠 How It Works

```text
Webcam
   ↓
Face Detection
   ↓
Eye / Facial Landmark Detection
   ↓
Eye Position Tracking
   ↓
Cursor Movement
   ↓
Blink Detection
   ↓
Mouse Click
